## What Is This Place?

Greetings, fellow web surfer! You have stumbled upon a **historic landmark** of the internet. This humble homepage has
the distinct honor of being **THE VERY FIRST APPLICATION** deployed to [Primcloud](https://primcloud.com)!

To commemorate this momentous occasion, we've built a tribute to the golden age of the World Wide Web - back when every
site had a visitor counter, a guestbook was _essential_, and animated GIFs roamed freely across the land.

## Getting Started (Fire Up Your Dial-Up!)

### Prerequisites

Before you begin your journey into cyberspace, ensure you have:

- **Node.js** (v18+ recommended)
- **PostgreSQL** (a database! fancy!)
- **A sense of nostalgia**

### Installation

```bash
# Clone this repository (or download the ZIP like it's 2003)
git clone https://github.com/joshmanders/hello-world.git

# Enter the directory
cd hello-world

# Install dependencies (grab a coffee, this might take a while on 56k)
npm install
```

### Environment Setup

Create a `.env` file based on the example:

```bash
cp .env.example .env
```

Then edit it with your database credentials:

```
DATABASE_URL=postgresql://user:password@localhost:5432/hello_world
```

### Database Setup

```bash
# Push the schema to your database
npm run db:push

# (Optional) Seed with sample guestbook entries
npm run db:seed

# Need a fresh start? Reset everything
npm run db:reset
```

### Launch!

```bash
# Start the development server
npm run dev
```

Then open http://localhost:3000 in your favorite browser (Netscape Navigator recommended).
